# A股下周罗盘

一个面向“下周一至周五大盘方向”的研究系统。它输出概率、收益区间、模型分歧、样本外回测与失效条件，不承诺盈利，也不连接券商自动下单。

## 当前方法

- 数据：上证指数、上证50、沪深300、中证500、中证1000、创业板指、恒生指数、标普500、纳斯达克和道琼斯的日线量价；腾讯证券主源，东方财富备用，本地缓存兜底。
- 特征：多周期动量、均线距离、波动率、RSI、振幅、量能、回撤、大小盘相对强弱、跨指数离散度。
- 模型：正则化逻辑回归、直方图梯度提升、随机森林；模型按滚动样本外准确率动态加权。
- 区间：Ridge、稳健梯度回归和历史相似状态共同估计，限制极端外推。
- 验证：5 折扩展窗口时序验证，训练/测试间留出 5 个交易日间隔；策略回测含单边 3bp 成本。
- 逐日验证：分别报告未来第 1–5 个交易日的全样本、最近 120 次、高置信区间命中率和覆盖率；只有同时超过近期基线与高置信门槛才显示中置信方向。
- 行业轮动：使用申万一级行业指数覆盖电子、计算机、通信、电力设备、公用事业、军工、汽车、医药、银行、非银、有色和食品饮料，并额外合成“科技综合”。行业绝对涨跌和相对沪深300强弱分别建模。
- 行业验证：行业面板按交易日期成组切分，避免同一天的数据跨训练集和测试集；页面同时报告最近 120 次第1日方向准确率、多数类基线和相对强弱概率。
- 事件冲击层：使用可审计的事件日历，按A股实际反应日聚合重大IPO、央行会议、宏观数据和海外科技财报；事件只改变风险标记和确认条件，不擅自修改未经回测的模型概率。
- 突发监控：额外列出政策监管、半导体限制、中报暴雷和地缘商品跳价的官方核验来源，未确认消息不进入方向信号。
- 观察池：从新浪当日成交额靠前的 A 股中预筛，再用腾讯 260 日复权行情按趋势、相对沪深300强弱、RSI、波动和流动性排序。观察池尚未完成无幸存者偏差的横截面回测，不是买入推荐。

## 启动

```powershell
py -m pip install -r requirements.txt
py automation.py --build
py -m uvicorn server:app --reload
```

然后打开 <http://127.0.0.1:8000>。页面右上角“重新计算”会调用同一套自动更新流水线。首次加入行业模型后，完整训练通常需要约 2–3 分钟。

## 版本7自动更新

自动更新入口为：

```powershell
py automation.py --build
```

流水线依次执行：

1. 抓取最新宽基、外围市场、行业、市场宽度和观察池数据。
2. 重新训练大盘与行业模型并运行滚动样本外验证。
3. 合并仅标记为“已确认”且带官方来源的短期事件。
4. 检查数据日期、5日结构、行业覆盖、验证样本、异常数值和日期倒退。
5. 门禁通过后原子替换 `public/data/forecast.json`；失败时保留上一版。
6. 写入 `data/automation/last_run.json` 和轮转日志，便于排错。

仅测试流程而不覆盖正式预测：

```powershell
py automation.py --dry-run
```

安装 Windows 定时任务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/install_windows_task.ps1
```

默认周一至周五 18:35、周日 20:30 执行。任务只在当前用户登录时运行；错过时间后会在系统可用时补跑。
任务在 Windows 任务计划程序中的名称是 `AShareCompass_AutoUpdate`。

> 当前公开站点是静态部署。定时任务会自动生成、校验并构建发布包，但不会持久保存短期部署令牌，因此线上更新仍需把通过门禁的版本发布到 Sites。这样可以避免把部署密钥写入磁盘。

## 与 ChatGPT 账号解耦的云端发布

项目包含 `.github/workflows/update-forecast-pages.yml`。把仓库放到 GitHub 并在
`Settings → Pages → Build and deployment` 中选择 `GitHub Actions` 后，云端会：

1. 工作日北京时间 18:35、周日 20:30 自动抓取、重训和运行质量门禁。
2. 门禁通过后发布 `public/` 到 GitHub Pages，并在线核验版本、5日结构和行业覆盖。
3. 把通过门禁的预测 JSON 提交回仓库，供下一次日期倒退检查使用。
4. 失败时停止发布，保留上一版 Pages，并保存 14 天诊断日志。

GitHub Pages 与 ChatGPT 账号无关；以后切换 ChatGPT 账号不需要更改站点项目编号。
首次推送到 GitHub 后，可在 `Actions` 页面手动运行一次
`Update forecast and deploy Pages`。公开仓库使用 GitHub Free 即可。

## 解释边界

样本外准确率略高于 50% 才是这类任务常见的真实尺度。预测概率会根据相对多数类基线的样本外能力向 50% 收缩；当模型分歧大或优势不足时，系统输出“震荡/观望”。第 2–5 日预测不应替代每日收盘后的重新训练。回测不是实盘承诺，政策、流动性、隔夜外盘和突发事件会使预测失效。
