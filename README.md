# A股下周罗盘

一个面向“下周一至周五大盘方向”的研究系统。它输出概率、收益区间、模型分歧、样本外回测与失效条件，不承诺盈利，也不连接券商自动下单。

## 当前方法

- 数据：上证指数、上证50、沪深300、中证500、中证1000、创业板指的日线量价；腾讯证券主源，东方财富备用，本地缓存兜底。
- 特征：多周期动量、均线距离、波动率、RSI、振幅、量能、回撤、大小盘相对强弱、跨指数离散度。
- 模型：正则化逻辑回归、直方图梯度提升、随机森林；模型按滚动样本外准确率动态加权。
- 区间：Ridge、稳健梯度回归和历史相似状态共同估计，限制极端外推。
- 验证：5 折扩展窗口时序验证，训练/测试间留出 5 个交易日间隔；策略回测含单边 3bp 成本。

## 启动

```powershell
py -m pip install -r requirements.txt
py generate.py
py -m uvicorn server:app --reload
```

然后打开 <http://127.0.0.1:8000>。页面右上角“重新计算”会重新拉取数据、训练模型并写入 `public/data/forecast.json`。

## 测试

```powershell
py -m pytest
```

如果没有安装 pytest：

```powershell
py -m pip install pytest
```

## 解释边界

样本外准确率略高于 50% 才是这类任务常见的真实尺度。预测概率会根据样本外能力向 50% 收缩；当模型分歧大或优势不足时，系统输出“震荡/观望”。回测不是实盘承诺，政策、流动性、隔夜外盘和突发事件会使预测失效。
